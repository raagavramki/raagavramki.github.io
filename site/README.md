# Raagav Ramakrishnan - Portfolio

## Update content
All site copy, projects, and links live in `site/lib/content.ts`.

- Profile: name, roles, badges, email, social links, resume URL, avatar
- About copy and skills list
- Projects list, tags, and filter labels
- Research and industry timeline entries
- Contact copy and toast messages
- Footer note

## Update assets
Place files in `site/public/assets`:

- `site/public/assets/img/profile.jpg`
- `site/public/assets/resume.pdf`

## Pages
App Router pages live in `site/app`:

- `site/app/page.tsx` (Landing)
- `site/app/about/page.tsx`
- `site/app/resume/page.tsx`
- `site/app/projects/page.tsx`
- `site/app/contact/page.tsx`

## Development
From `site/`:

- `npm install`
- `npm run dev`
